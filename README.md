# The Chronicle Museum

A virtual museum website built with only **HTML, CSS and JavaScript** (no frameworks or libraries) as part of the Semester 1 Web Development Project.

The page shows museum exhibits as cards, lets visitors filter them by historical period, and opens a detailed pop-up (modal) when a card is clicked. A timeline explains the three periods: Ancient, Medieval and Modern.

## Features

- Exhibit cards, each with an image, name, period and description
- Timeline of periods (Ancient, Medieval, Modern) built with CSS borders
- Elegant dark gallery-style theme
- Hover effect on cards that reveals more details
- Filter buttons to show exhibits by historical period
- Click a card to open a detail modal (closes with the × button, a click outside, or the Escape key)
- Responsive layout for mobile screens

## How to Run

1. Download or clone this repository.
2. Open the `index.html` file in any web browser.

No installation is needed.
